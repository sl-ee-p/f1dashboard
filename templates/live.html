About Live Timing
Note: F1 live timing requires an active race weekend broadcast. Outside of sessions, the feed will connect but receive no meaningful data.
📡 Live data comes from the F1 SignalR stream via the fastf1.livetiming module
🏎 Only works during an active FP, Qualifying, or Race session — not between events
🔑 No F1 account needed — the public feed is used. See the fastf1 docs for full setup
⚡ The backend emits data via WebSocket every 2 seconds during an active stream
